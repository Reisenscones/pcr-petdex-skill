# 验收、交付与常见问题

验收强度遵从用户要求。本 skill 本次制作只做静态检查；下面是**以后实际制作桌宠时**可按需执行的检查，不代表已经执行。用户不要求环境复现时，不创建虚拟机或模拟新系统。

## 静态检查

- 工具清单与路径明确，骨骼和 atlas 同 basename，所有 atlas 页存在；源码不依赖原仓库或原电脑。
- 配置指向应用内路径，所有动画名称/时长来自查询，必需键及至少一个 packing_XX 齐全，别名不自循环。
- v2 清单引用的图片存在，可见帧、时长、高清原点、分段与掌心数量匹配；没有把 local state 当成发布资源。
- 保留许可证及素材归属；新角色来源按实际填写。

## 人工动作验收

用 preview-hochan.cmd 关闭真实观察器，在右键菜单依次预览每个动作；检查完整循环、单次动作结尾和拼接接缝。图像要完整、不跳位置、无透明黑/白边；悬浮保留原本离地高度，武器不裁切。

按住角色左右拖动、停住一个完整悬浮循环、缓慢反向、快速拖动及松手；确认手掌跟鼠标、停住不抖、反向不频闪、松手恢复任务动作且没有中间错位帧。检查 75/100/125/150% 大小、Windows 100/125/150/200% DPI；有多屏时跨屏观察，没测到的组合明确标为未验证。

检查四边收纳露出完整头像、展开不抢焦点、主窗口和头像恢复置顶；检查右键菜单、气泡隐藏、大小记忆、角色切换及失败回退。休息只在空闲允许，点击挥手唤醒。

联动验收在实际客户端中观察思考→工具→完成、压缩、权限与子代理；权限气泡的允许/拒绝均需用户实际点击。未启用联动则无需改用户配置来完成独立桌宠验收。

## 附带自动验收工具

均位于生成应用的 tools/，使用该应用 .venv/Scripts/python.exe 执行。部分检查会开真实窗口或创建隔离状态；不要在用户拒绝模拟/运行验证时执行。

| 场景 | 工具和适用范围 |
| --- | --- |
| 单个已构建角色的完整窗口流程 | `verify_runtime.py --character <id>`，先确保 preview/ 存在 |
| 模型主角色导出帧、拖动、菜单、渲染 | verify_skin.py、verify_drag_anchor.py、verify_menu.py、verify_rendering.py，原主角色资源布局专用 |
| 原项目两套角色均已构建 | verify_characters.py、verify_pipeline.py、verify_size.py、verify_drag_start.py、verify_stationary_drag.py |
| 原项目拼接动作历史回归 | verify_compaction.py，除两套资源外还需要 source/reference-frames/manifest.json 原始研究导出记录；普通构建不产生该文件，不作为新电脑基本验收 |
| 生命周期优先级 | verify_turn_start.py |
| Hook 安装器与实际桥接 | verify_hooks.py，使用隔离 CodexHome，但尾段需要原主角色资源 |
| 原项目资源清理约束 | verify_cleanup.py，需要两套完整资源及匹配的文档；不适合缺素材模板 |
| 性能测量 | profile_runtime.py --character <id> --size-percent 150，实际窗口计时 |

不要对只有一个新角色的项目盲跑要求“两套参考资源齐全”的全套回归，再把缺少参考素材误判为新角色损坏。先看工具的角色/目录假设，必要时将检查改为目标角色。

verify_autostart_lifetime.py 会重启本项目监测器和桌宠；它不属于普通验证命令。只有明确要验证实际自启动生命周期时才使用，不在清单检查中运行。

## 常见问题

| 症状 | 检查与处理 |
| --- | --- |
| CLI 启动报 framework 缺失 | .NET 8 x64 的 Core/WindowsDesktop 运行时是否存在，是否误下 Linux 包 |
| 导出器缺 --fixed-view | 用错工具/版本；恢复固定发行包，不以自动 bounds 代替 |
| 模型加载失败或贴图空白 | 骨骼版本、同名 atlas、多页纹理相对路径、PMA 设置；先在 Viewer 检查源素材 |
| 脚手架映射失败 | 动画不存在或后缀不唯一，手工编辑映射，不强行猜测 |
| duration mismatch | 重新 query，sequence 时长求和，不用帧数反猜源时长 |
| transparent or clipped frame | 统一扩大视野/补下方画布；检查槽可见性，不关闭检查掩盖错误 |
| handB/Offset 报错 | 槽名或 attachment 类型不同，按校准参考选槽/扩展导出器 |
| 站立高度跳变 | 自动 bounds 或每动作 scale 不一致，重新统一视区 |
| 鼠标不动但画面抖 | 掌心采样不一致、整数取整或小数 DPI 采样网格漂移 |
| 首次拖动卡顿 | 检查悬浮首帧预热，鼠标线程不能临时解码/缩放 |
| 双击立刻退出 | 用 python 控制台看异常及 startup-error.log，确认素材已构建、.venv 属于本机 |
| 只有思考/完成，没压缩/权限 | 核对 Hook 审查、事件支持、是否仍在隔离预览；无审批请求本就无权限气泡 |
| 退出 Codex 桌宠也被杀 | 后台监测器是否落在调用者作业内，保留 WMI/breakaway 启动路径 |

## 交付内容

给出实际项目路径、启动命令、操作说明、工具与安装入口、角色来源、检查结果及未验证项。保留源码、requirements.txt、配置、生产 assets、许可证；不分享 .venv、state、Codex 数据、权限请求或 build 历史。单文件 exe、多平台、自动升级不在当前模板的默认交付范围。
