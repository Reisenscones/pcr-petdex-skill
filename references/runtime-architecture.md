# 运行框架与实现约束

模板含当前项目实际源码，优先复制后调整，而非凭说明重写一套行为近似但缺失细节的播放器。运行无需原项目路径。

## 透明窗口与性能

主窗口用 Win32 layered window 和 UpdateLayeredWindow 提交逐像素 alpha。透明区不应挡住其他软件；角色可见区用于点击/拖动。动画只改变窗口显示内容，正常运行不抢焦点。

- 以独立 60Hz 呈现时钟发消息，使用实际时间计算帧。后台被菜单或系统阻塞时跳到当前帧，不积压旧帧。
- 呈现消息至多保留一个后续请求；允许当前更新执行时排入下一次请求，避免略超 deadline 就掉到 30Hz。
- 后台准备提前六帧，处理解码、缩放和像素转换。GUI 线程提交已准备好的帧、叠加动态气泡与效果。
- 主帧缓存按字节约束到 128MiB，子角色缩放图另有 32MiB。不要按“缓存所有动作”预解码全部高清帧。
- 缓存角色占用区，保留其画布原点。DIB/DC 交替复用，每帧清空透明区；角色、大小或 DPI 改变时失效相应缓冲。
- 拖动时窗口坐标与位图一次提交，首帧和当前已显示帧有独立缓存，详见校准参考。

## 角色、设置与 UI

`characters/*/character.json` 指向 skin 和生产资源。每次开菜单重新扫描，未构建角色禁用，损坏配置不拖垮其他角色。切换前验证全部资源；成功后主角色、子角色与边缘头像一起切换，任务状态、尺寸保持，选择写当前状态目录 pet-settings.json。

主菜单顺序为设置、动作预览、切换角色、日志、关于、退出。设置有随 Codex 启动、隐藏任务气泡栏、75/100/125/150% 大小。权限气泡不随隐藏任务栏选项隐藏。拖动和边缘动画过渡期间禁用切换。

休息只在无活动任务、权限或庆祝时进入；点击播放唤醒一次。手动预览覆盖任务动作，菜单提供恢复实际联动。庆祝、随机动作、展开与唤醒按各自单次规则结束；压缩随机播放完整动作。

调整大小保持根骨屏幕位置，必要时把角色移回工作区。角色、子角色、掌心、命中区域、气泡、头像统一使用显示缩放，不能只 resize 位图。

主窗口和边缘头像定期恢复置顶，保持位置、大小与焦点；菜单打开期间暂停定期调整，菜单结束/边缘展开时立即恢复。不要用持续激活窗口实现置顶。

## 事件、线程与数据隔离

状态存储以任务/会话及轮次区分；旧轮次事件不能覆盖新轮次。观察器第一次读到 task_started 时进入思考，只有实际工具事件才进入执行。子代理显示独立演员和独立动作进度。

Codex 数据库、rollout、日志扫描放后台，后台不共享 GUI 可变任务状态。事件回传 GUI 后仍经过原有轮次/时间戳判断。权限 IPC 请求要等待相应轮次事件，不能在旧状态清理阶段误删。

正式 state 与 preview/验收 state 分开；心跳名 pcr-heartbeat.json，状态/设置使用原子写入。错误查看 startup-error.log、事件 JSONL 和构建报告，不通过覆盖全局配置消除错误。
